# Фон-видео для /login и /register (веб) — что встроено

Фон витрины страниц входа и регистрации — беззвучный видео-тур из трейлера ProtoMap
(решение Ориона 29.10.2026; монтаж в ритм трека-ориентира, звука нет: прав на
распространение нет, и браузеры запускают видео только `muted`).

> **Правка 31.10.2026.** Файлы больше не лежат в репозитории (`static/auth/`), а
> раздаются из **Firebase Storage** — путь `public/film/v1/`. Так тяжёлые ролики
> (~114 МБ на сайт) не висят в git и не идут через Vercel. Решение Ориона: видео на
> Storage, тариф Blaze, по прогнозу бесплатно (см. ниже).

## Раскладка

`/login` и `/register` используют общий шелл `src/lib/components/auth/AuthShell.svelte`:
десктоп (≥1024px) — две колонки, слева витрина, справа форма; телефон (<1024px) — только
форма, витрина скрыта (`display:none`). Видео — фон витрины (`object-fit: cover`), поверх
него скрим снизу, счётчик «протогенов на карте», уголки-рамка и подпись карты.

**На телефоне видео нет** — витрина скрыта, тяжёлый файл не грузится. Гейт в JS по
`matchMedia('(min-width:1024px)')`, а не только CSS: `display:none` не гарантирует, что
браузер не скачает медиа. У приложения — свой формат 9:16, он подключается в репозитории
приложения (те же файлы на Storage, папка `public/film/v1/`).

## Форматы и файлы (Firebase Storage, `public/film/v1/`)

| Где | Соотношение | Файлы |
| --- | --- | --- |
| Витрина сайта (десктоп) | 1:1 (рендер 1440×1440) | `login-1x1.{webm,mp4}` (RU), `login-1x1-en.{webm,mp4}` (EN) |
| Постеры сайта | 1:1 | `login-1x1.webp`, `login-1x1-en.webp` |
| Приложение | 9:16 (1080×1920) | `login-9x16[-en].mp4`, `login-9x16[-en].webp` |

Текст интерфейса вшит в кадр, поэтому у RU и EN свои файлы. Язык выбирается по `$locale`
(`en*` → суффикс `-en`, иначе RU; `ru_april` регистрируется под кодом `ru` и отдельного
файла не требует). Смену языка на странице `{#key}` пересобирает `<video>`.

Исходники файлов студия кладёт в `trailer/out/film/` (вне git). В Storage их заливает
сервер/админ (Admin SDK) — клиентам запись и листинг закрыты правилами.

## Как раздаётся

Прямая ссылка без токена, по правилу Storage `allow get: if true` на `public/film/**`:

```
https://firebasestorage.googleapis.com/v0/b/protomap-1e1db.firebasestorage.app/o/public%2Ffilm%2Fv1%2Flogin-1x1.webm?alt=media
```

- Эндпоинт `?alt=media` поддерживает HTTP Range → `<video>` стримится и перематывается,
  приложение докачивает с места обрыва.
- Токена в адресе нет (`getDownloadURL` не нужен), адрес постоянный. **Новая версия фильма —
  новая папка** (`v2`, …), а не замена файла: приложение кеширует по адресу.
- На файлах стоит `Cache-Control: public, max-age=31536000, immutable` — вернувшиеся
  посетители не перекачивают ролик, трафик Storage расходуется в основном на новых.
- CORS для фонового `<video>` без атрибута `crossorigin` не нужен (и у бакета не задан).

## Воспроизведение

- `<video autoplay muted loop playsinline poster>`, первым `<source>` webm (VP9), вторым
  mp4 (H.264). ~69 с, бесшовный луп.
- Постер (`.webp`) — это и SSR/no-JS фолбэк, и кадр при `prefers-reduced-motion: reduce`
  (видео тогда не грузим вовсе).
- Вес: webm ~19 МБ, mp4 ~38 МБ (сайт 1:1); постер ~0,16 МБ.

## Поверх видео рисует страница — в кадр не вшивать

- Заголовки, подписи и счётчик «протогенов» — это оверлей витрины, не часть видео.
- **Скрим снизу обязателен**: внизу кадра разное (карта, карточка слотов с балансом),
  без затемнения счётчик сталкивается с цифрами из кадра.
- **Подпись карты** «OpenFreeMap © OpenMapTiles © OpenStreetMap» — статично, мелко, в
  свободном верхнем правом углу витрины. В кадр не вшита (`cover` бы срезал её на краю).
- Без сезонного оформления в кадре — сезонность отдельный слой сайта.
- Чистая комната: без скриншотов старого приложения и QR на старую Play-страницу.

## Стоимость (прогноз 31.10.2026)

Бакет `protomap-1e1db.firebasestorage.app`, регион us-central1, тариф Blaze. Тип
`firebasestorage.app` → бесплатно 5 ГБ-месяцев хранения и **100 ГБ/мес** скачивания.
Всё видео ~180 МБ (сайт + приложение) = ~3,6 % места. При 238 пользователях и ~8 новых
в месяц месячный трафик видео — единицы ГБ; до платного порога (~2,7–4 тыс. загрузок/мес)
очень далеко. Сверх 100 ГБ — тариф Cloud Storage ~$0.12/ГБ.
