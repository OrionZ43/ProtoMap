# Фон-видео для /login и /register (веб) — что встроено

Фон страниц входа и регистрации — беззвучный видео-тур из трейлера ProtoMap (решение Ориона
29.10.2026; монтаж в ритм трека-ориентира, звука нет: прав на распространение нет, и браузеры
запускают видео только `muted`). Файлы раздаются из **Firebase Storage** (`public/film/v2/`),
а не из репозитория — тяжёлые ролики не висят в git и не идут через Vercel.

> **Финал 31.10.2026.** После серии итераций с Орионом: НЕ двухколоночная витрина и НЕ квадрат
> 1:1, а **широкий фильм 16:9 на весь экран** (`v2`), поверх плавное затемнение и **безрамочная
> форма по центру** (поля прямо на видео, без коробки). Квадрат 1:1 (`v1`) под `cover` резал
> вшитый в кадр текст — студия отрендерила широкий 16:9, он кроется ~9%, титры/экраны читаются.

## Раскладка

`/login` и `/register` используют общий шелл `src/lib/components/auth/AuthShell.svelte`: фильм —
фон на всю страницу (`object-fit: cover`), **закреплён за окном** (`position: fixed; inset: 4rem
0 0 0; height: calc(100vh - 4rem)`), чтобы кроп не зависел от высоты формы (иначе вход и
регистрация кропались бы по-разному). Поверх: затемнение-столб, плёночное зерно, форма по центру,
подпись карты. Коробки/контейнера у формы нет — поля лежат прямо на затемнённом видео.

**Телефон (<1024px):** тяжёлое видео не грузим — показываем вертикальный постер `login-tall.webp`
(один на оба языка). Гейт в JS по `matchMedia('(min-width:1024px)')`, а не только CSS. У приложения
свой экран входа (тот же дизайн, формат 9:16, читает `v1`), подключается в его репозитории.

## Форматы и файлы (Firebase Storage, `public/film/v2/`)

| Где | Соотношение | Файлы |
| --- | --- | --- |
| Десктоп (≥1024px) | 16:9, 2560×1440 | `login-wide.{webm,mp4}` (RU), `login-wide-en.{webm,mp4}` (EN) |
| Постер десктопа | 16:9 | `login-wide.webp`, `login-wide-en.webp` |
| Постер телефона | 9:19.5 | `login-tall.webp` (1080×2340, один на оба языка, без титров) |

Текст интерфейса вшит в кадр, поэтому у RU и EN свои широкие файлы. Язык по `$locale` (`en*` →
суффикс `-en`, иначе RU; `ru_april` под кодом `ru`). Смену языка `{#key}` пересобирает `<video>`.
Исходники студия кладёт в `trailer/out/film_wide/` (вне git); в Storage заливает сервер/админ
(Admin SDK). `v1` (`login-1x1`, `login-9x16`) НЕ удаляем — `login-9x16` читает приложение.

## Как раздаётся

Прямая ссылка без токена по правилу Storage `allow get: if true` на `public/film/**`:

```
https://firebasestorage.googleapis.com/v0/b/protomap-1e1db.firebasestorage.app/o/public%2Ffilm%2Fv2%2Flogin-wide.webm?alt=media
```

- `?alt=media` поддерживает HTTP Range → `<video>` стримится и перематывается.
- Токена в адресе нет, адрес постоянный. `Cache-Control: public, max-age=31536000, immutable` —
  вернувшиеся не перекачивают. **Новая версия фильма — новая папка** (`v3`, …), а не замена файла:
  из-за immutable-кэша браузеры иначе возьмут старое.
- CORS для фонового `<video>` без `crossorigin` не нужен (у бакета не задан).

## Воспроизведение

- `<video autoplay muted loop playsinline poster>`, первым `<source>` webm (VP9), вторым mp4
  (H.264, moov в начале). ~68,6 с, бесшовный луп.
- **Автоплей запускаем явно** (`on:loadeddata`/`on:canplay` → `v.muted = true; v.play()`): Svelte
  не отражает атрибут `muted` в свойство, и беззвучный автоплей иначе блокируется (см. `.jules/bolt.md`).
- Постер — SSR/no-JS фолбэк и кадр при `prefers-reduced-motion: reduce` (видео тогда не грузим).
- Вес: webm ~41 МБ, mp4 ~47 МБ (десктоп 16:9); постеры ~0,19 МБ; `login-tall` 0,16 МБ.

## Форма и затемнение (рисует страница, в кадр не вшивать)

- Поля **безрамочные**: подпись сверху + иконка слева + подчёркивание (в фокусе прорисовывается
  акцентная линия) + подсказка-плейсхолдер; у пароля кнопка-глазик. Тени на тексте — для читаемости.
- **Затемнение** — вертикальный столб по центру (где форма); край зависит от ширины окна
  (`--f: min(8rem, 6vw)`), чтобы не гасить окно сайта в кадре на ноутбуках. Плюс плёночное зерно.
  Фон/скрим/зерно/подпись — `position: fixed` за окном.
- Счётчика «PROTOMAP NETWORK» нет (убран по просьбе Ориона). Заголовок и подпись — оверлей.
- Подпись карты «OpenFreeMap © OpenMapTiles © OpenStreetMap» — мелко, в нижнем правом углу.
- Чистая комната: без скриншотов старого приложения и QR на старую Play-страницу.

## Проверка и стоимость

Проверено в Chromium на 2560/1920/1536/1366/1024 + мобайл, RU/EN: видео играет со Storage,
Range 206, без чёрных полей, титры/экраны по бокам читаются. **Safari не проверен** (Playwright =
Chromium); на iPhone видно только постер (форма узкая), видео смотреть на Mac/iPad в альбомной.

Бакет `firebasestorage.app` в us-central1 (Blaze): бесплатно 5 ГБ-месяцев хранения и **100 ГБ/мес**
скачивания. При 238 пользователях и ~8 новых/мес трафик видео — единицы ГБ; до платного порога
далеко. Сверх 100 ГБ — тариф Cloud Storage ~$0.12/ГБ.
